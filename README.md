<h1>📚 TechTales – Historias y Aprendizajes sobre Tecnología y Desarrollo</h1>

<h2>🔧 Descripción del Proyecto (Backend)</h2>
<p>
    <strong>TechTales</strong> es una plataforma comunitaria que permite a los entusiastas del desarrollo compartir historias y enfrentarse a retos de programación. 
    El backend, construido con <strong>ASP.NET Core .NET 8</strong>, está diseñado con <strong>arquitectura limpia</strong> para mantener una estructura sólida, escalable y mantenible. 
    La seguridad se maneja mediante <strong>JWT</strong>, y se han añadido servicios de notificación, integración con Firebase y almacenamiento en la nube.
</p>

<h2>🚀 Características Principales</h2>
<ul>
    <li>📚 <strong>Historias de la comunidad</strong>: Los usuarios publican sus experiencias y conocimientos sobre tecnología.</li>
    <li>🏁 <strong>Retos propuestos por el administrador</strong>: Desafíos únicos que los usuarios pueden completar y registrar.</li>
    <li>💬 <strong>Comentarios</strong>: Participación activa mediante comentarios en historias y retos.</li>
    <li>✅ <strong>Seguimiento de retos completados</strong>: Registro de los desafíos cumplidos por los usuarios.</li>
    <li>🔐 <strong>Login seguro con JWT</strong>: Acceso autenticado para usuarios y administradores.</li>
    <li>📧 <strong>Servicio de notificaciones</strong>: Envío de correos electrónicos personalizados vía SMTP con <strong>Scriban</strong> como motor de plantillas.</li>
    <li>☁️ <strong>Almacenamiento en Cloudinary</strong>: Gestión eficiente de imágenes y recursos en la nube.</li>
    <li>🔐 <strong>Login con Google (Firebase)</strong>: Autenticación con cuenta de Google para mayor accesibilidad.</li>
    <li>📑 <strong>Documentación con Swagger</strong>: API autodescriptiva para facilitar el consumo de endpoints.</li>
</ul>

<h2>🧪 Pruebas Unitarias</h2>
<p>
    El proyecto incorpora un enfoque profesional de calidad de software mediante <strong>pruebas unitarias</strong> con <strong>XUnit</strong> y <strong>Moq</strong>, asegurando la fiabilidad de la lógica de negocio y el correcto funcionamiento de los servicios principales.
</p>

<h2>✨ Tecnologías Utilizadas</h2>
<ul>
    <li>🖥 <strong>ASP.NET Core .NET 8</strong> para una API moderna y robusta.</li>
    <li>🏗 <strong>Arquitectura Limpia</strong> para separación de responsabilidades y escalabilidad.</li>
    <li>🛢 <strong>Entity Framework Core + MySQL</strong> para el manejo de la base de datos.</li>
    <li>🔐 <strong>JWT</strong> y <strong>Firebase Auth</strong> para autenticación segura.</li>
    <li>📧 <strong>SMTP + Scriban</strong> para envío de correos con plantillas HTML dinámicas.</li>
    <li>☁️ <strong>Cloudinary</strong> para almacenamiento de medios.</li>
    <li>🧪 <strong>XUnit + Moq</strong> para pruebas unitarias y simulación de dependencias.</li>
    <li>📖 <strong>Swagger</strong> para explorar y probar los endpoints de la API.</li>
</ul>

<h2>🧱 Estructura de Base de Datos</h2>
<ul>
    <li><strong>Usuarios</strong>: Registro y autenticación.</li>
    <li><strong>Historias</strong>: Publicaciones de los usuarios.</li>
    <li><strong>Retos</strong>: Desafíos propuestos por el administrador.</li>
    <li><strong>Comentarios</strong>: Opiniones y participación comunitaria.</li>
    <li><strong>VotosHistorias</strong>: Reacciones a historias.</li>
    <li><strong>RetosCompletados</strong>: Historial de desafíos completados.</li>
</ul>
